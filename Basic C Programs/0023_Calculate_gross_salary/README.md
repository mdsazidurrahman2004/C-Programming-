# Gross Salary Calculation

This is a basic C program that takes the basic salary and other allowance as input from the user using the `scanf()` function and calculates the gross salary.

The program uses `int` variables to store the gross salary, basic salary, and other allowance. The `int` data type is used because these values are whole numbers.

The `scanf()` function is used to take the basic salary and other allowance as input. The `%d` format specifier is used because the variables `basic_salary` and `other_allowance` are declared as `int`.

The statement `gross_salary = basic_salary + other_allowance;` calculates the gross salary by adding the basic salary and other allowance. The `+` operator is used for addition, and the calculated result is stored in the `gross_salary` variable.

The `printf()` function displays the calculated gross salary. The `%d` format specifier is used to display the integer value of the gross salary.

## Output

Enter basic salary: 20000

Enter other allowance: 5000

Gross salary is 25000
