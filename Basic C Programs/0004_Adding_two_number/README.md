# Add Two Numbers

This is a basic C program that takes two integer numbers as input from the user using the `scanf()` function and calculates their sum using the `+` operator.

The program uses `int` variables to store the two input numbers and the result of the addition.

The `scanf()` function is used to take integer input. The `%d` format specifier is used because the variables `num1` and `num2` are declared as `int`.

The statement `sum = num1 + num2;` adds the two numbers and stores the result in the `sum` variable. The `printf()` function is then used to display the calculated sum.

## Output

Enter number A: 4

Enter number B: 5

The sum of A and B is 9
