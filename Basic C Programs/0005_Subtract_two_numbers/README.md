# Subtraction of Two Numbers

This is a basic C program that takes two integer numbers as input from the user using the `scanf()` function and calculates their difference using the `-` operator.

The program uses `int` variables to store the two input numbers and the result of the subtraction.

The `scanf()` function is used to take integer input. The `%d` format specifier is used because the variables `num1` and `num2` are declared as `int`.

The statement `result = num1 - num2;` subtracts `num2` from `num1` and stores the result in the `result` variable. The `printf()` function is then used to display the calculated result.

## Output

Enter number A: 5

Enter number B: 3

The result of subtraction is 2
