# Remainder of Two Numbers

This is a basic C program that takes two integer numbers as input from the user using the `scanf()` function and finds the remainder using the `%` operator.

The program uses `int` variables to store the two input numbers and the result of the remainder operation.

The `scanf()` function is used to take integer input. The `%d` format specifier is used because the variables `num1` and `num2` are declared as `int`.

The statement `result = num1 % num2;` finds the remainder when `num1` is divided by `num2` and stores the result in the `result` variable. The `printf()` function is then used to display the calculated remainder.

## Output

Enter number A: 3

Enter number B: 5

The remainder of A and B is 3
